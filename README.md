# Ahmed Fath Elpap — Personal Website

A responsive personal digital business card / portfolio website built with plain HTML and CSS, ready for GitHub Pages.

## Publish it at https://fath-elpap.github.io/

1. Sign in to GitHub as **Fath-elpap**.
2. Create a **Public** repository named exactly `Fath-elpap.github.io` (the name must match the username, including capitalization as shown).
3. Extract this ZIP file.
4. Upload the contents of the `ahmed-personal-website` folder to the repository root. The root should contain `index.html`, `style.css`, `README.md`, `.nojekyll`, and the `assets` folder.
5. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to finish deploying. The site should be available at `https://fath-elpap.github.io/`.

## Included assets

- `assets/Ahmed_Fath_Elpap_CV.pdf` — CV PDF
- `assets/graduation-project-infographic.jpg` — graduation project infographic

## Updating the site
Replace the relevant file in `assets` while keeping the same filename, then commit the change to the repository. GitHub Pages will redeploy automatically.
