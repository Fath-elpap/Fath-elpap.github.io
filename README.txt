# Ahmed Fath Elpap — Digital Business Card

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository named `Fath-elpap.github.io` under the GitHub account `Fath-elpap`.
2. Upload the contents of this folder (the `index.html` file and the `assets` folder) to the repository root.
3. In Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, then Save.
4. Your site should appear at https://fath-elpap.github.io/ after GitHub finishes deployment.
